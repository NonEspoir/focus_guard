# FocusGuard 使用教程

## 1. 下载与安装

1. 打开 [Releases 页面](https://github.com/NonEspoir/focus_guard/releases)，下载最新版本的 `FocusGuard-x.y.z.zip`。
2. 双击 zip 解压，得到 `FocusGuard.app`。
3. 把 `FocusGuard.app` 拖进「应用程序」文件夹。

**系统要求**：macOS 14 (Sonoma) 及以上，Apple 芯片和 Intel 芯片都支持。

## 2. 第一次打开（必看）

FocusGuard 没有经过 Apple 公证，第一次打开时系统会拦截，提示 “无法验证开发者” 或 “Apple 无法检查其是否包含恶意软件”。这是正常的，按下面的方法放行一次即可，之后就能正常打开。

**方法一：系统设置（macOS 15 必须用这个）**
1. 双击 FocusGuard，看到警告后点「完成」或「取消」。
2. 打开「系统设置 → 隐私与安全性」，滚动到最下面的「安全性」部分。
3. 找到 “已阻止 FocusGuard……”，点旁边的「仍要打开」，输入密码确认。

**方法二：终端（一条命令）**
```bash
xattr -dr com.apple.quarantine /Applications/FocusGuard.app
```
执行后再双击打开即可。

## 3. 界面在哪里

- FocusGuard 是**菜单栏工具**，打开后在屏幕右上角的菜单栏出现一个 ⌖ 图标。默认不在程序坞显示，可以在「设置 → 选项 → 外观」里打开「在程序坞中显示图标」，之后点程序坞图标也能呼出主面板。
- 打开时会弹出主面板窗口。
- **菜单栏图标看不到？** 菜单栏空间不够时（尤其是带刘海的 MacBook），macOS 会直接隐藏图标。可以：
  - 从启动台或 Spotlight 再次打开 FocusGuard，会弹出主面板；
  - 按住 ⌘ 把图标拖到靠右的位置，它就不容易被挤掉。

## 4. 设置黑名单 / 白名单

在主面板点「设置…」。「App」页和「网站」页**各自**可以选择黑名单或白名单模式：

- **黑名单**：专注时只拦截名单里的。
- **白名单**：专注时只允许名单里的，其它一律拦截。

专注期间（提醒模式和硬核模式都一样）不能切换黑名单 / 白名单。

两种名单的数据是分开保存的。比如网站从黑名单切到白名单，看到的是白名单（一开始为空），原来的黑名单只是隐藏起来，切回去就还在。

**「App」页**
- 黑名单默认包含「活动监视器」，避免专注时在里面强制退出 FocusGuard。不需要的话可以删掉，删掉后不会再自动加回来。
- 「从『应用程序』添加…」：在应用程序文件夹里选，可以多选。
- 「从运行中的 App 添加」：直接从正在运行的 App 里选。
- 白名单模式下，访达和系统设置始终允许。**记得把你用的浏览器也加进白名单**，否则浏览器会被拦截。
- 白名单模式只拦截显示在屏幕上的 App，开始专注时不会把后台挂着的 App 一次性全关掉。

**「网站」页**
- 黑名单预置了 bilibili.com、weibo.com、douyin.com、xiaohongshu.com、youtube.com，可以增删。
- 输入域名即可，比如 `bilibili.com`。粘贴完整网址也行，会自动提取域名。
- 子域名会一起匹配，比如 `bilibili.com` 包括 `www.bilibili.com`、`m.bilibili.com`。
- 白名单模式下，localhost、浏览器新标签页和设置页始终允许。

## 5. 开始专注

在主面板选时长、选模式，点「开始」。专注期间菜单栏显示倒计时。

| | 提醒模式 | 硬核模式 |
|---|---|---|
| 打开黑名单 App | 隐藏 App，弹出全屏遮罩 | 直接关闭 App |
| 打开黑名单网站 | 弹出全屏遮罩 | 直接关闭该标签页 |
| 临时放行 | 等待 10 秒并写下理由，放行 5 分钟 | 不能放行 |
| 提前结束 | 需要写理由 | 每天只有一次机会 |
| 退出 FocusGuard | 可以 | 会话期间不能正常退出 |
| 修改规则 | 可以（但不能切换黑白名单） | 只能收紧：黑名单只能加，白名单只能删，不能切换黑白名单 |

**建议先用提醒模式**跑一两天，确认黑名单没有误伤，再切到硬核模式。

所有拦截、放行理由和提前结束记录，都可以在「设置 → 记录」里查看，保留 30 天。

## 6. 浏览器权限

网站拦截不需要安装浏览器插件，FocusGuard 通过 macOS 的 AppleScript 读取浏览器网址。

- **支持**：Safari、Chrome、Edge、Brave、Arc。
- **不支持**：Firefox。
- 第一次拦截网页时，系统会弹窗：“FocusGuard” 想要控制 “Microsoft Edge”（或其他浏览器）。**请点「允许」**，否则网站拦截不会生效。
- 如果不小心点了「不允许」：到「系统设置 → 隐私与安全性 → 自动化 → FocusGuard」里，把对应的浏览器打开。

## 7. 开机自启

「系统设置 → 通用 → 登录项」，在「登录时打开」里点「+」，选择 FocusGuard。

## 8. 常见问题

**拦截有延迟？**
切换 App 和网页时，最多 2 秒内会被检测到。

**哪些情况拦不到？**
- 浏览器里没在显示的后台标签页（切过去之后才会拦）
- 最小化到 Dock 的浏览器窗口
- Edge 分屏时的另一半
- 用浏览器「安装为 App」的网站：它们是独立的 App，需要在「App」页设置，而不是「网站」页

**硬核模式下强制退出 FocusGuard 会怎样？**
强制退出能让拦截暂时停止，但下次打开 FocusGuard 时，未结束的会话会自动恢复。

**数据存在哪里？**
`~/Library/Application Support/FocusGuard/`，删掉这个文件夹即可清空所有设置和记录。

**怎么卸载？**
先在菜单栏退出 FocusGuard，然后把「应用程序」里的 FocusGuard.app 删掉，需要的话再删除上面的数据文件夹。
